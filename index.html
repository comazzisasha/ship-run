ABOUT SHIP RUN: GEOMETRY DASH ONLINE FAN GAME

Play a Geometry Dash online fan game, free with no download

Ship Run is a free Geometry Dash fan game built around GD ship mode. Hold to fly up, let go to fall, and steer through spikes, saws, thorn pits, blocks and portals in fast rhythm platformer levels. It is an HTML5 browser game, so you can play Geometry Dash-style levels online right here, with no download, no install and no login.

How to play

Hold Space, the Up arrow, the mouse button or your finger to fly the ship up, and let go to fall. Press Esc to pause. Play starts a random run of 5 levels back to back; crash once and a new run starts. Practice mode lets you replay any single level as many times as you like and collect its user coins.

Features

  • Ship mode levels inspired by Clubstep, Clutterfunk, Cycles, ElectroDynamix, Nightmare, Necropolis and more.
  • Speed portals (half to quad speed), gravity portals, mini and big size portals, teleport portals, pads and orbs.
  • A Geometry Dash-style level editor: editor layers, Edit Group, Edit Object, color triggers, alpha triggers and testing.
  • Geometry Dash art, backgrounds and ground, with low, medium and high graphics and a Low Detail Mode.

Play on PC, Chromebook, Mac or mobile

Ship Run works in Chrome, Edge, Firefox and Safari on Windows PCs, Macs, Chromebooks, iPhones, iPads and Android phones and tablets. There's no app or extension to install.

Frequently asked questions

Is Ship Run Geometry Dash online?
Ship Run is a free Geometry Dash online fan game, not the official game by RobTop Games. It plays like Geometry Dash ship mode and runs in your browser at ship-run.world.
Is Ship Run free?
Yes. Ship Run is completely free, with no ads, no in-app purchases and no account.
Do I need to download anything?
No. Ship Run is an HTML5 browser game, so there is no download, install, extension or login. It works in Chrome, Edge, Firefox and Safari.
Can I play on a Chromebook, PC, Mac or phone?
Yes. Ship Run runs in the browser on Chromebooks, Windows PCs, Macs, iPhones, iPads and Android phones and tablets.
Is Ship Run Geometry Dash unblocked?
Ship Run runs straight from ship-run.world with no download or extension, so you can play wherever that site opens. Whether a school or work network allows it depends on that network's rules.
Does it have practice mode and a level editor?
Yes. Practice lets you replay any level on its own, and the level editor (in dev mode) has editor layers, Edit Group, Edit Object, color triggers and testing.
